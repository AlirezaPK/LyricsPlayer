# 🎵 Lyrics Player

A simple, Android music player built with **Kotlin** and **Jetpack Compose**. It leverages **Media3** to deliver robust background playback, system media notifications, and a seamless user experience.

## ✨ Key Features
- 🎧 **Background Playback**: Music continues playing seamlessly when the app is minimized or the screen is locked, powered by a `MediaSessionService`.
- 🔔 **System Integration**: Fully functional media notification and lock-screen controls (Play, Pause, Next, Previous).
- 📜 **Synchronized Lyrics**: Parses `.lrc` files from assets and displays them with smooth auto-scrolling.
- 🎯 **Active Line Highlighting**: The current lyric is dynamically highlighted with smooth alpha animations, and tapping any line instantly seeks the audio to that timestamp.
